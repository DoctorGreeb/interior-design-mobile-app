# 🏡 Interior Design — Мобильное приложение для дизайна интерьеров

Кроссплатформенное мобильное приложение (iOS + Android), полностью адаптированное под управление пальцами на смартфоне.

## Возможности

- **Главный экран** — быстрый старт, шаблоны комнат, советы дизайнера
- **Каталог мебели** — поиск, фильтры по категориям, размеры и цены
- **Планировщик комнаты** — 2D-холст с перетаскиванием мебели (drag & drop), поворот, удаление
- **Мои проекты** — сохранение и просмотр созданных интерьеров
- **Профиль** — избранное, настройки, тёмная тема

## Особенности UX для смартфонов

- Крупные touch-targets (минимум 44×44 pt)
- Нижняя навигация с удобным расположением под большой палец
- Горизонтальные чипы категорий и мини-каталог
- Плавные жесты (react-native-gesture-handler + reanimated)
- Portrait-only, оптимизировано под одну руку

## Стек

- **Expo SDK 52** + React Native
- TypeScript
- React Navigation (Bottom Tabs + Native Stack)
- React Native Gesture Handler + Reanimated

## Запуск

```bash
# Установка зависимостей
npm install

# Запуск в Expo Go
npx expo start

# Или сразу на эмулятор / устройство
npx expo start --android
npx expo start --ios
```

Отсканируйте QR-код в приложении **Expo Go** на телефоне.

## Структура проекта

```
├── App.tsx                 # Корневой компонент + навигация
├── src/
│   ├── screens/            # Экраны приложения
│   ├── components/         # Переиспользуемые компоненты
│   ├── data/               # Каталог мебели и шаблоны
│   └── constants/          # Тема, цвета, отступы
└── assets/                 # Иконки и splash
```
